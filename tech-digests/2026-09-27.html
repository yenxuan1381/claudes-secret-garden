01

The $78,000 Codex Runaway

What it is

A developer's routine OpenAI Codex request from VS Code spun up 826 parallel child agent tasks that ran unsupervised overnight, burning through roughly $78,000 in API charges before anyone noticed — and per the ensuing Hacker News and GitHub issue threads, the platform's own records of what the swarm actually did were largely gone, leaving the user unable to reconstruct what happened.

Why people care

It's the most concrete "agent goes feral and racks up a bill you never saw coming" story yet — not a benchmark or a hypothetical, but one production account with no spend guardrail catching a fork-bomb of sub-agents until the invoice arrived, and it's reopened the fight over whether liability for an unauthorized agent spend sits with the platform or the user.

For you

If your firm is piloting any agentic coding tool with real API billing behind it, this is the exact failure mode worth pressure-testing before wider rollout: hard per-task spend caps and mandatory human sign-off before an agent can spawn child agents, not just a soft usage alert you might not see until the statement closes.

Could Be Big A real, sourced dollar-figure incident forcing a genuine liability debate, though it's one account's failure so far rather than proof of a systemic platform flaw.

02

Breaking Up with Google Play

What it is

Daniel Gultsch, solo developer of the decade-old federated XMPP messaging app Conversations, made it permanently free on Google Play after securing multi-year grant funding (NLnet and the European Commission, through 2029), and moved primary distribution to F-Droid with reproducible, self-signed builds.

Why people care

It's a rare, well-documented case of an indie developer walking away from app-store revenue — and its 15% cut, opaque review delays, and unexplained takedowns — the moment an alternative funding model made it possible, which is a real data point on what sustainable open-source software can look like outside the app-store toll booth.

For you

Mostly a case study rather than a direct opportunity, but genuinely useful if you think about software business models: it's evidence that public grant funding can substitute for app-store monetization on a mature niche product, which matters for how you'd value or model similarly grant-backed open infrastructure elsewhere.

Promising A real, sustained decision from a developer with a decade of track record and secured funding through 2029, not a stunt — but a single niche app, not yet a broader trend.
gultsch.de/posts/breaking-up-with-google-play
03

Univer 1.0

What it is

Chinese startup DreamNum shipped 1.0 of Univer, an open-source (Apache-2.0) "office harness" bundling spreadsheets, docs, slides, canvases, relational tables, and PDFs into one embeddable runtime with a shared plugin system — plus a new Server SDK and AI SDK so an agent can read, generate, and edit real office documents instead of just plain text.

Why people care

AI agents today mostly manipulate text; genuinely useful office work — a real formula-driven spreadsheet model, a formatted deck, a live dashboard — needs an actual office engine underneath it, and this is one of the first mature, permissively-licensed ones built specifically so an agent, not just a human, can drive it.

For you

Squarely relevant to finance work — an agent that builds and edits a real spreadsheet model through an SDK, formulas and all, is a meaningfully different capability than a chatbot pasting numbers into a table, and worth watching if you'd want in-house tooling that produces actual Excel-like deliverables rather than text to copy in by hand.

Could Be Big A 1.0 release, not a demo, from a team that already ships a real spreadsheet product, addressing a gap every "agent does office work" pitch currently glosses over.
github.com/dream-num/univer
04

Floci

What it is

An open-source, MIT-licensed suite (built with Quarkus Native) that emulates roughly 45 AWS services plus Azure and GCP equivalents locally — S3, DynamoDB, Lambda, RDS, and more, running on real Docker containers and real Postgres/Redis underneath — starting in about 24 milliseconds with no account, auth token, or paid tier.

Why people care

LocalStack's free tier has narrowed over time and paid unlocks have crept into what used to be free local cloud testing; Floci is a direct, fully-free response that's also fast enough — near-instant startup — to fit inside an AI coding agent's tight test-and-iterate loop, not just a human's.

For you

If your team runs any cloud-dependent test suites or CI pipelines, this is a genuinely swappable cost- and friction-reducer — no new procurement, no account, just point existing AWS SDK calls at it locally instead of a paid emulator.

Promising Solves a real, recently-worsened pain point with a credible technical approach, but young against an incumbent with years of edge-case coverage.
floci.io
05

Is My Migration Safe?

What it is

A single-purpose web tool parses a pasted Postgres migration — using libpg_query compiled to WebAssembly, entirely client-side — and flags statements that would take dangerous locks or trigger full-table rewrites on a large production table, the same statement that's a no-op on a 500-row staging table.

Why people care

Untested schema migrations are one of the most common ways teams take down production databases, and this turns "is this actually safe at real scale" into a ten-second browser check that never sends a private schema to a server.

For you

A small but immediately usable safety net if your team ships its own database migrations — including ones an AI coding agent wrote, which the author specifically calls out as newly risky, since agents produce syntactically correct SQL that looks safe but isn't.

Promising Narrow and unglamorous, but a real, working tool for a well-understood, expensive failure mode, with a CLI path for wiring straight into CI.
safenotsafe.dev
06

Drawgent

What it is

A single Rust binary from one developer spins up a live Excalidraw canvas that your existing Claude Code, Codex, or opencode agent can see and edit directly — ask for a diagram in chat, or annotate the canvas with an "AGENT: ..." note, and the agent screenshots the scene, redraws it, and iterates until it's clean.

Why people care

Most AI-generated diagrams today are one-shot and never touched again; this closes the loop so an agent can inspect its own diagram, notice overlapping labels or bad arrow routing, and fix it live, then commit the result as a real .excalidraw file that stays in the repo alongside the code it describes.

For you

Mostly just cool for now — a nice trick for keeping architecture diagrams in sync with code, but a solo weekend-scale project rather than something to build a workflow around yet.

Toy Clever and well-executed, but a single-developer tool with no track record yet.
tangled.org/yanndegat.tngl.sh/drawgent
