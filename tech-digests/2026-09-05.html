Tech Discoveries

Six things getting real attention right now — a from-scratch open-source Docker Desktop rival for Macs, a switchboard for juggling eight different AI coding tools, memory that survives you closing your agent, a phone turned into a studio mic, a Go compiler that skips cgo's tax entirely, and one solo researcher's AI-assisted exploit archive.

01

ArcBox

What it is

An open-source container and VM runtime for Apple Silicon Macs, built from scratch in Rust — its own hypervisor, network stack, and VirtIO devices, not a wrapper around someone else's. One runtime handles Docker-compatible containers, full Linux VMs, macOS guest VMs, and sub-100ms AI-agent sandboxes.

Why it lands

OrbStack and Docker Desktop both charge once you're a team, and neither lets you read the code underneath. ArcBox is a public-beta, MIT/Apache-2.0 answer built by a small team — and it's having a big day: it gained 567 stars today alone, roughly a fifth of its total 2,887.

For you

A concrete line to test against your Docker Desktop Business or OrbStack Teams renewal if you run a Mac-based engineering org — same job, no per-seat license.

Promising Real hypervisor-level engineering in public beta — exactly the layer where edge cases bite a young project hardest.
github.com/arcboxlabs/arcbox
02

CC Switch

What it is

A free desktop app for Windows, Mac, and Linux that puts one visual switcher in front of eight different AI coding tools — Claude Code, Codex, Gemini CLI, and more — for their configs, API providers, and MCP servers, instead of hand-editing a different JSON or TOML file for each.

Why it lands

Running more than one agent tool is now normal, and each one wants its own config format and its own place to paste an API key. CC Switch collapses all of that into one tray-accessible switcher with cloud sync — it's picked up another 182 stars today on top of 131,000+.

For you

Squarely useful if your team already runs more than one of these tools side by side — it's the unglamorous key-and-config management layer that saves real minutes every day, not a business case by itself.

Promising Already deep and load-bearing for a lot of people, but it's a convenience layer over other people's tools, not a moat.
github.com/farion1231/cc-switch
03

ai-memory

What it is

A Rust tool that gives AI coding agents memory that outlives the session: quit Claude Code mid-task, start Codex in the same folder, and it already knows what happened, across 20+ supported agents and even across machines via a shared server.

Why it lands

Normally an agent's context dies the moment you close the window or switch tools, and the next agent — or the next person — starts from zero. ai-memory captures session notes automatically through hooks and turns them into searchable wiki pages the next agent can pull from before it starts working.

For you

If your team already runs more than one agent against the same codebase, this closes a real continuity gap — handoffs between agents, or between you and a colleague's agent session, stop re-explaining everything.

Promising Solves a genuine, common annoyance, but it only pays off once a whole team actually adopts the hook.
github.com/akitaonrails/ai-memory
04

MicYou

What it is

An app that turns an Android phone into a wireless or USB microphone for your computer, routing audio through a real processing pipeline — AI and traditional noise suppression, echo cancellation, automatic gain control — rather than just passing the raw signal through.

Why it lands

A decent USB mic runs $50–150; most people already carry a phone with a better mic than their laptop's. MicYou streams that audio to a virtual device so any app on your desktop just sees a normal microphone, no dedicated hardware required.

For you

Mostly just cool — though it's a genuine few-dollars-saved trick for kitting out a home office or a team's meeting-room laptops on a budget.

Toy Well-built and free, but a personal convenience app, not something with a business angle.
github.com/LanRhyme/MicYou
05

llgo

What it is

A Go compiler built on LLVM that keeps ordinary Go syntax but compiles straight down to code that speaks C's calling convention natively, so it can call into — or be called from — C, Python, and JavaScript libraries with no cgo layer sitting in between.

Why it lands

cgo works, but it carries real runtime overhead and friction any time Go code needs to talk to the C ecosystem. This week's Console.dev newsletter summed up llgo's pitch as "FFI performance without FFI" — Go treated as a first-class citizen of the C world instead of a guest paying a toll to get there.

For you

Narrow but real: relevant if any of your stack bridges Go services to C or Python numerical libraries — pricing engines, risk models — where this is exactly the kind of primitive that quietly removes a latency tax later.

Promising A serious compiler project 6,600+ commits deep, but still tied to specific Go and LLVM versions, and early for production use.
github.com/xgo-dev/llgo
06

Exploitarium

What it is

A public archive of 50+ proof-of-concept exploits and vulnerability writeups — covering software like Firefox, OpenSSH, and Discord — built and published by one independent researcher who says the fuzzing work behind the findings was largely AI-automated.

Why it lands

It's a live data point for what "AI lowers the barrier to vulnerability research" actually looks like: one person, without a professional security team behind them, finding and documenting real, previously undocumented bugs at a pace that used to take a group. The repo carries an explicit disclaimer against malicious use and encourages formal CVE disclosure.

For you

Worth knowing about even if you never open the repo — it's a preview of your own threat model: the cost of finding an exploitable bug in software you depend on just dropped for researchers and attackers alike.

Promising The findings look real, but the whole story depends on disclosure staying responsible — that's the tension, not a side note.
github.com/bikini/exploitarium
