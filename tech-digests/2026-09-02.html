01

Slotstream

What it is

A tool that runs Qwen3.8-Flash-Next — a 125B-parameter model that normally needs 104GB of RAM at 4-bit — on a Mac with as little as 48GB, by streaming only the "expert" weights it needs off SSD instead of loading the whole model into memory. It's built in Swift on MLX and exposes an Ollama-compatible API.

Why it lands

The standard fix for "model too big" has been "buy more RAM." Slotstream treats the SSD as a much bigger, slightly-slower RAM instead, and gets a genuinely usable ~12 tokens/sec out of it — enough that the Show HN thread pulled 134 points and 84 comments.

For you

If your team runs large open-weight models locally for cost or data-privacy reasons, this technique — not necessarily this exact tool — changes the hardware math for who can afford to run a 125B-class model at all.

Promising Real, working, MIT-licensed — but Apple Silicon only, one developer, early days.
github.com/carloslfu/slotstream
02

fff

What it is

A file-search engine shipped as one Rust core with thin bindings for C, Python, Node/Bun, and Neovim, built to start once and stay warm in memory instead of being re-launched as a fresh process on every search. It adds fuzzy path matching, content grep, git-status awareness, and frecency ranking on top.

Why it lands

ripgrep and fzf are fast per call, but an AI coding agent that runs hundreds of searches a session pays the cost of spawning a new process and re-scanning the filesystem every time — 3-9 seconds per call on a repo the size of Chromium, versus sub-10ms once fff's index is warm.

For you

The pattern is the takeaway, not the tool: if you're running agents over large codebases or document sets, a warm resident index beats shelling out repeatedly — it's already inside opencode and nushell.

Promising 10.4k stars and already load-bearing in real projects, but it's plumbing, not a product.
github.com/dmtrKovalenko/fff
03

Scientific Agent Skills

What it is

A library of 165 "skills" that plug into agents like Claude Code, Cursor, and Codex, each one teaching the agent how to correctly use one specific scientific database or method — cancer genomics, drug-target binding, molecular dynamics, regulatory literature search, and more.

Why it lands

A generic coding agent doesn't know how to correctly query a genomics database or validate a PK/PD model; these skills package that domain expertise so it doesn't hallucinate its way through a scientific workflow. It gained roughly 900 stars in one day and is now the #3 repo on GitHub's trending page.

For you

Not finance-specific, but it's a live, at-scale example of "bundle domain process and guardrails into a skill" — the exact pattern an equity-research or diligence team would want to build for its own playbook.

Could be big Claimed 190k+ users and fast institutional-scale growth in a domain where being wrong is costly.
github.com/K-Dense-AI/scientific-agent-skills
04

trading-skills

What it is

A tiny open-source pack of Claude Code skills that turn 68 real investors and traders — Buffett, Jim Simons, Michael Burry, Ray Dalio, and others — into personas that weigh in as you discuss a trade, plus a pre-trade risk gate and a "tilt detector" for emotional trading.

Why it lands

It's genuinely funny — "SBF's ghost shows up when you forget a stop-loss" — sitting on top of a real, useful primitive: encoding one investor's actual discipline (position sizing, what invalidates a thesis) as something an agent can apply, not just impersonate.

For you

Squarely your lane: if you're already using Claude Code for analysis, it's a free, five-minute way to test whether a "reason like investor X" skill is a useful way to red-team your own trade or thesis writeups.

Toy 18 stars, one developer, days old — but a clean example of a pattern turning up across several repos right now.
github.com/VictorVVedtion/trading-skills
05

OpenSEO

What it is

A self-hosted, open-source SEO platform — keyword research, rank tracking, competitor and backlink analysis, site audits — that you run yourself and pay for only the underlying data API calls, instead of a $100-500+/month Semrush or Ahrefs seat.

Why it lands

Semrush and Ahrefs are expensive, closed SaaS platforms; OpenSEO takes the same workflows and makes them free to run and inspect, and ships an MCP server so an AI agent can query your SEO data mid-conversation instead of you exporting spreadsheets. It's back on GitHub's trending page today with a fresh spike of stars.

For you

A concrete cost lever if you or a portfolio company pays for SEO tooling today — and structurally it's the "unbundle the expensive incumbent SaaS into open, pay-as-you-go plus AI-agent hooks" move worth watching in other categories too.

Promising 16k+ stars and a Product Hunt #1 day already behind it, but data coverage still trails the incumbents it's copying.
github.com/every-app/open-seo
